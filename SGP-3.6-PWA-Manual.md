# Manual curto — SGP 3.6 (PWA iPhone)

App web progressivo alinhado ao **SGP Mac 3.6**, para uso no iPhone sem App Store.

## Abas
| Aba | Função |
|-----|--------|
| **Hoje** | Contadores e lista de prazos a partir do cache local |
| **Lista** | Comunicações pendentes + atalhos Portal/eproc |
| **Espelho** | Tabela espelho; ordenação Início/Final; seleção; arquivar local |
| **Extrair** | Abrir SGP, colar texto/HTML, importar CSV, exportar CSV, CNJ manual |
| **Portais** | SGP, Portal Advogado, eproc 1G/2G, PJe JF, PJe TRF5 (Safari) |
| **Ajustes** | URLs editáveis |

## Ordenação
No Espelho, toque em **Início do Prazo** ou **Final do Prazo**: 1× crescente, 2× decrescente. A linha inteira se move.

## Limitações vs Mac
- Sem navegador embutido: portais abrem no Safari.
- Arquivar não grava no SGP remoto — só marca local.
- Sem Touch ID do Mac; Face ID do iPhone não é o mesmo fluxo.
- Sem Keychain autofill do Mac.
- XLSX: prefira CSV do Exportar do SGP.
- Não é app da App Store (PWA).

## Dados
Tudo fica em localStorage neste iPhone.
